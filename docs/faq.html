FAQ

How the tracker works

Short answers about where the data comes from and how the site interprets it.

Where do the stats come from?

Levels, XP, boss KC and historical snapshots come from Wise Old Man data saved by the tracker.

Where does the Collection Log come from?

Collection Log data is imported through Temple and then saved for the group site.

What does Item value mean?

It is the estimated GE value of the quantities currently stored in each member’s saved Collection Log. Untradeable or unpriced items contribute 0 gp.

Why can historical dates be approximate?

WOM snapshots record account states at specific times. If a level or milestone happened between two snapshots, the tracker can identify the interval but not the exact moment.

Does the site refresh automatically?

No. WOM and Temple are refreshed manually with the update buttons so the shared data changes deliberately.

What does the member filter affect?

The selected members control comparisons, charts and Collection Log views throughout the site. Group-wide masthead totals continue to use the full five-member group where applicable.
