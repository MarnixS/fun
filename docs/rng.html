RNG Index Log

The flagship luck model for The United Gimps. It separates raw probability from account value, then asks whether the RNG that actually happened was meaningfully fortunate or unfortunate for a mature Group Ironman.
Collection Log Advanced ↗How RNG Index Log works ↗
Core idea: meaningful RNG is built from evidence × item impact × context/rank modifier. Evidence asks how unusual the roll was. Impact asks how useful that exact item is. Context adjusts for copies, group coverage, components, raid portfolios and the fact that with hundreds of possible drops something obscure will eventually look lucky by chance.
