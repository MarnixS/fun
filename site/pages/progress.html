Dates and data coverage

Latest period compares each player’s first and last valid observations leading up to the latest group update. Personal bests uses every saved interval to prove minimum records, including the gains that longer intervals imply for shorter windows. ≥ means at least: unsaved gaps can hide higher gains. Record bars, gain lists and comparisons use the same proven minimums; a bound with unknown run dates is never drawn as a timeline. Evidence dates below refer to the source interval, which can exceed the selected window.

A zero recent gain means the displayed counters did not change. A zero record minimum can leave unseen gains unknown. A dash means insufficient history. Screenshot XP uses level minimums and day-only dates; record proofs allow for their uncertainty. A genuine counter correction restarts the comparison. Lines connect saved observations across gaps.

    Time Records uses the same personal-best calculation and shows all six windows side by side. The combined minimum can include runs from different dates. It is not a simultaneous group record.
